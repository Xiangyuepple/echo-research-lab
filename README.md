# Echo Research Institute

一本正经地研究下班、午饭和日常好奇心的静态互动网页。

线上地址：https://echo-anomaly.pages.dev/

## 玩法

- 加班倾向检测：完成三道选择题，按答案给出结果。
- 午饭委员会：筛选辣度与食量，抽取并确认午饭提案。
- 今日签：按浏览器本地日期固定签文。
- 好奇心压力测试：等待绿灯后点击，支持键盘空格，抢跑不计入完成。
- 假如研究室：把假设转成一个小行动。
- 下班后的平行宇宙：按精力选择晚间安排。

完成三个不同实验后解锁可署名、复制和打印的结案证书。重复实验不重复计数。

## 本地运行

在仓库目录执行 `python3 -m http.server 8766`，访问 http://localhost:8766/。

无依赖、无构建步骤，源文件为 `index.html`。

## Cloudflare Pages

- 生产分支：`main`

现有 GitHub Pages 工作流保留。

## 数据

网页不包含聊天导出、人物画像、私人聊天原文、分析报告或第三方追踪脚本。进度、昵称和最佳反应成绩只保存在当前浏览器的 localStorage，不上传。清理网站数据或使用页面底部的清空功能即可删除这些本机记录。

实验结论与签文为虚构趣味内容，不用于评估真实人格或能力。
